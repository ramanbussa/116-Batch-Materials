# End-to-End CI/CD Pipeline Implementation Guide

## GitHub → Jenkins → Maven → SonarQube → Nexus → Tomcat (AWS EC2)

This document explains the complete implementation steps for students to build a real-time CI/CD pipeline using AWS EC2 servers.

---

# 1. Architecture Overview

## Components Used

| Component        | Purpose                       | Server               |
| ---------------- | ----------------------------- | -------------------- |
| GitHub           | Source code repository        | Cloud                |
| Jenkins          | CI/CD automation server       | EC2                  |
| Maven            | Build tool                    | Installed on Jenkins |
| SonarQube        | Code quality analysis         | EC2                  |
| Nexus Repository | Artifact storage              | EC2                  |
| Tomcat           | Application deployment server | EC2                  |

---

# 4. Install Jenkins

Connect:

```bash
ssh ubuntu@<jenkins-public-ip>
```

Update packages:

```bash
sudo apt update
```

Install Java:

```bash
sudo apt install openjdk-17-jdk -y
```

Verify:

```bash
java -version
```

---

Install Jenkins:

```bash
curl -fsSL https://pkg.jenkins.io/debian-stable/jenkins.io-2023.key | \
sudo tee /usr/share/keyrings/jenkins-keyring.asc > /dev/null
```

Add repository:

```bash
echo deb [signed-by=/usr/share/keyrings/jenkins-keyring.asc] \
https://pkg.jenkins.io/debian-stable binary/ | \
sudo tee /etc/apt/sources.list.d/jenkins.list
```

Install:

```bash
sudo apt update

sudo apt install jenkins -y
```

Start:

```bash
sudo systemctl enable jenkins

sudo systemctl start jenkins
```

Access:

```
http://<jenkins-ip>:8080
```

Get password:

```bash
sudo cat /var/lib/jenkins/secrets/initialAdminPassword
```

# 7. Setup SonarQube Server

SSH:

```bash
ssh ubuntu@<sonarqube-ip>
```

Install Java:

```bash
sudo apt install openjdk-17-jdk -y
```

Download SonarQube:

```bash
wget https://binaries.sonarsource.com/Distribution/sonarqube/sonarqube.zip
```

Install:

```bash
unzip sonarqube.zip

sudo mv sonarqube /opt/sonarqube
```

Create user:

```bash
sudo useradd sonar

sudo chown -R sonar:sonar /opt/sonarqube
```

Start:

```bash
cd /opt/sonarqube/bin/linux-x86-64

./sonar.sh start
```

Access:

```
http://<sonarqube-ip>:9000
```

Default login:

```

password:
admin
```

# 11. Configure Tomcat Manager

Edit:

```bash
sudo vi /opt/tomcat/conf/tomcat-users.xml
```

Add:

```xml
<role rolename="manager-script"/>

<user username="manager"
password="Admin@123"
roles="manager-script"/>
```

---

Allow Jenkins remote access:

Edit:

```
/opt/tomcat/webapps/manager/META-INF/context.xml
```

Comment:

```xml
<!--
<Valve className="org.apache.catalina.valves.RemoteAddrValve"
allow="127\.\d+\.\d+\.\d+|::1"/>
-->
```

Restart:

```bash
/opt/tomcat/bin/shutdown.sh

/opt/tomcat/bin/startup.sh
```

# 13. Create Jenkins Pipeline

Create:

```
New Item

Name:
cicd-pipeline

Type:
Pipeline
```

---

Pipeline Script:

```groovy
pipeline {

agent any


tools {
    maven 'Maven'
}


stages {


stage('Checkout') {

steps {

git branch:'master',
url:'https://github.com/ramanbussa/war-web-project.git'

}

}


stage('Build') {

steps {

sh 'mvn clean package'

}

}


stage('SonarQube Analysis') {

steps {

withSonarQubeEnv('sonarqube') {

sh '''
mvn org.sonarsource.scanner.maven:sonar-maven-plugin:sonar \
-Dsonar.projectKey=wwp \
-Dsonar.projectName=wwp
'''

}

}

}


stage('Quality Gate') {

steps {

timeout(time:10, unit:'MINUTES') {

waitForQualityGate abortPipeline:true

}

}

}


stage('Upload WAR to Nexus') {

steps {

nexusArtifactUploader(

nexusVersion:'nexus3',

protocol:'http',

nexusUrl:'<nexus-private-ip>:8081',

repository:'wwp-release',

credentialsId:'nexus-creds',

groupId:'com.example',

version:"${BUILD_NUMBER}",


artifacts:[

[
artifactId:'wwp',
classifier:'',
file:'target/wwp-1.0.0.war',
type:'war'
]

]

)

}

}


stage('Deploy Tomcat') {

steps {

deploy(

adapters:[

tomcat9(

credentialsId:'tomcat_creds',

url:'http://<tomcat-private-ip>:8080'

)

],

contextPath:'wwp',

war:'target/wwp-1.0.0.war'

)

}

}


}


post {

success {

echo "CI/CD Pipeline Completed Successfully"

}

}

}
```
